\section*{\textcolor{blauPista}{Qüestió 2}}

\noindent Considereu el sistema d'equacions següent:
\[
\left.\begin{array}{r}
4x + 2y - z = 4 \\
x - y + kz = 3 \\
3x + 3y = 1
\end{array}\right\},
\]
on $k$ és un paràmetre real.

\subsection*{\textit{a)} \normalfont Discutiu el sistema per als diferents valors del paràmetre $k$, i resoleu-lo per a $k = 0$. \hfill\textnormal{[1~punt]}}

\pista{Aquest apartat té dues parts: discutir i resoldre. Per discutir el sistema, escriu la matriu de coeficients $A$ i la matriu ampliada $A^{'}$, calcula $\det(A)$ i troba els valors de $k$ que l'anul·len. Per a cadascun d'aquests valors, compara els rangs d'$A$ i $A^{'}$. I què passa amb els rangs per a la resta de valors de $k$? Després resol el sistema per a $k = 0$: comprova primer si aquest valor anul·la $\det(A)$. Què et diu això sobre el tipus de sistema i el nombre de solucions?}

\subsection*{\textit{b)} \normalfont Resoleu el sistema per a $k = -1$. \hfill\textnormal{[0,75~punts]}}

\pista{Recorda què has trobat a l'apartat a) per a aquest valor de $k$. Si és compatible indeterminat, pren una variable com a paràmetre (per exemple $x = \lambda$) i expressa les altres dues en funció de $\lambda$.}

\subsection*{\textit{c)} \normalfont Per a $k = -1$, modifiqueu la tercera equació de manera que el sistema esdevingui incompatible. Justifiqueu la resposta. \hfill\textnormal{[0,75~punts]}}

\pista{Has d'aconseguir que els rangs d'$A$ i $A^{'}$ no coincideixin. Per a $k=-1$, fixa't quina relació hi ha entre la tercera equació i les altres dues: quina part n'has de canviar perquè el rang d'$A$ es mantingui però el d'$A^{'}$ augmenti? Justifica-ho comparant els rangs.}
