\section*{\textcolor{blauPista}{Qüestió 3}}

\noindent Sigui el sistema d'equacions lineals
\[
\left.\begin{array}{r}
2x + y = 1 + z \\
my + z = 2 - x \\
mz + 3 = 3x + y
\end{array}\right\},
\]
en què $m$ és un nombre real.

\subsection*{\textit{a)} \normalfont Discutiu el sistema segons els valors del paràmetre $m$. \hspace*{\fill}\textnormal{[1,25~punts]}}

\pista{Abans de res, reorganitza el sistema: les incògnites a l'esquerra, en l'ordre $x$, $y$, $z$, i les constants a la dreta.

\medskip
Discuteix el sistema amb el teorema de Rouché-Frobenius:
\begin{itemize}
\item escriu la matriu de coeficients $A$ i la matriu ampliada $A^{'}$;
\item calcula $\det(A)$ i troba els valors d'$m$ que l'anul·len;
\item per a cadascun d'aquests valors, compara els rangs d'$A$ i d'$A^{'}$;
\item no oblidis el cas $\det(A) \neq 0$.
\end{itemize}

\medskip
\textbf{Atenció:} vigila els signes quan canviïs termes de costat.}

\subsection*{\textit{b)} \normalfont Resoleu el sistema, si té solució, per al cas $m = 1$. \hspace*{\fill}\textnormal{[1,25~punts]}}

\pista{Substitueix $m = 1$ al sistema reorganitzat.
\begin{itemize}
\item Abans de resoldre'l, mira a quin cas de la discussió de l'apartat \textit{a)} correspon: quantes solucions tindrà?
\item Després resol-lo per Gauss.
\end{itemize}

\medskip
\textbf{Drecera:} la primera i la tercera equacions tenen els mateixos coeficients d'$y$ i de $z$, o els oposats, segons com hagis passat els termes de costat. Si les restes o les sumes, obtens directament una de les incògnites.}
