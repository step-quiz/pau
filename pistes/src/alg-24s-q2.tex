\section*{\textcolor{blauPista}{Qüestió 2}}

\noindent Considereu el sistema d'equacions següent, on $m$ és un paràmetre real:
\[
\left.\begin{array}{r}
x - 3y + mz = -2 \\
x + my + 2z = 3 \\
x + y + 2z = m
\end{array}\right\}
\]

\subsection*{\textit{a)} \normalfont Discutiu el sistema segons el valor del paràmetre $m$. \hfill\textnormal{[1,25~punts]}}

\pista{Discuteix el sistema amb el teorema de Rouché-Frobenius:
\begin{itemize}
\item escriu la matriu de coeficients $A$ i la matriu ampliada $A^{'}$;
\item calcula $\det(A)$ i troba els valors de $m$ que l'anul·len;
\item per a cadascun d'aquests valors, compara els rangs d'$A$ i d'$A^{'}$;
\item no oblidis el cas $\det(A) \neq 0$.
\end{itemize}

\medskip
\textbf{Consell:} abans de calcular cap rang, substitueix el valor al sistema i mira'l: de vegades salta a la vista que dues equacions no es poden complir alhora.}

\subsection*{\textit{b)} \normalfont Trobeu la solució del sistema per a $m = 0$. \hfill\textnormal{[0,5~punts]}}

\pista{Substitueix $m = 0$ al sistema.
\begin{itemize}
\item Abans de resoldre'l, mira a quin cas de la discussió de l'apartat \textit{a)} correspon: quantes solucions tindrà?
\item Després resol-lo, per exemple, per Gauss.
\end{itemize}}

\subsection*{\textit{c)} \normalfont Per a $m = 2$, doneu una solució $(x, y, z)$ del sistema que, a més a més, compleixi $x = 5y$. \hfill\textnormal{[0,75~punts]}}

\pista{Per a $m = 2$, parteix de la discussió de l'apartat \textit{a)}:
\begin{itemize}
\item queda't amb les equacions independents;
\item pren una incògnita com a paràmetre (per exemple $z = \lambda$) i expressa les altres dues en funció de $\lambda$;
\item imposa la condició $x = 5y$: obtindràs el valor de $\lambda$ i, amb ell, els valors de $x$, $y$ i $z$.
\end{itemize}}
